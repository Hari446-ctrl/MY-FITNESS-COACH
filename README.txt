MY FITNESS COACH — ANDROID PROJECT

BUILD YOUR APK:
1. Install Android Studio.
2. Extract this ZIP.
3. In Android Studio choose Open and select the My_Fitness_Coach_Android folder.
4. Allow Gradle sync and install Android SDK Platform 35 if prompted.
5. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Find the APK at app/build/outputs/apk/debug/app-debug.apk.
7. Transfer it to your Android phone and install it. Allow installation from that source if Android asks.

Includes three bodyweight workouts, exercise cues and easier options, warm-up/cool-down guidance, 30/60/90-second rest timer, and local workout history.
This ZIP contains source code, not a precompiled APK. Workout history is stored locally; clearing app data erases it. Stop any exercise that causes pain.
